# Student Management System

## About the Project
A web application developed using Python and Django to manage student records.

## Technologies Used
- Python
- Django
- HTML
- CSS

## Features
- Add student details
- View student details
- Update student details
- Delete student details

## Project Structure
```text
Student-Management-System/
├── config/
├── students/
├── db.sqlite3
├── main.py
├── manage.py
└── README.md
```

## Installation
1. Clone this repository.
2. Install Django:

   ```bash
   pip install django
   ```

## How to Run
Run the following command in the project directory:

```bash
python manage.py runserver
```

Open the local server address displayed in the terminal in your browser.
